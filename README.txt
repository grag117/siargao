FEEL AND DISCOVER SIARGAO — WEBSITE PROJECT
===========================================

Files:
- index.html : complete responsive website (HTML, CSS, JavaScript in one file)

HOW TO TEST:
1. Extract this ZIP.
2. Open the feel_and_discover_siargao folder.
3. Double-click index.html to preview it in a browser.
4. Internet access is needed for the remote Unsplash photos and Google Map.

HOW TO PUBLISH WITH GITHUB PAGES:
1. Sign in to https://github.com/
2. Create a NEW public repository, e.g. feel-and-discover-siargao
3. Upload index.html to the repository root (not inside an extra folder).
4. Open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait a few minutes and refresh the Pages settings. Open the published URL shown there.
8. Test the URL in an incognito/private window or on a phone not signed in to GitHub.

BEFORE SUBMITTING:
- Replace the sample email hello@feeldiscover-siargao.example with a real email you control, in both the contact section and form script. The .example address is intentionally non-functional.
- Add your actual Facebook/Instagram page links if you create them.
- Sample package prices and inclusions are illustrative; confirm any factual or operational details before presenting them as real.
- The form is a demonstration: it prepares an email request and does not store reservations or confirm availability. For real submissions, connect Google Forms, Formspree, or another form backend.
- Images load from Unsplash URLs and require internet access.
- Create a QR code only after your GitHub Pages site is live. Use the exact public homepage URL, then scan-test the QR code.
